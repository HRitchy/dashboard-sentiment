# Dashboard Sentiment

Application Next.js de suivi du sentiment de marché, centrée sur les indicateurs quantitatifs :

- VIX
- HY OAS
- Fear & Greed
- NFCI
- S&P 500

## Démarrage

```bash
npm run dev
```

Ouvrez ensuite [http://localhost:3000](http://localhost:3000) dans votre navigateur.

## Scripts

```bash
npm run lint
npm run build
```

## Configuration

Copiez `.env.example` vers `.env.local` si vous souhaitez renseigner une clé FRED optionnelle.
